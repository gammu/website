{% trans "Support for Wammu and Gammu" %}

{% blocktrans %} Gammu and Wammu are free software projects. As such you can get some support from the community behind the project. The best place to start is usually the documentation, where many configuration issues and common situations are already covered. {% endblocktrans %}

{% blocktrans %} If you are looking for list of supported phones, you can look into Gammu Phone Database. You can also share your experiences there, but if you had problems, please report bugs and do not write about problems only in phone database. {% endblocktrans %}

{% trans "Community Support" %}

{% blocktrans %} If the documentation does not help, ask the community on the Gammu discussion forum. You can also use the forum to share ideas and experiences. {% endblocktrans %}

{% trans "Reporting Bugs" %}

{% blocktrans %} Once you think you have hit a bug or want to file a feature request, please use a bug tracker to report them. Please be as descriptive as possible and include the information needed to reproduce the bug, such as debug logs. Security vulnerabilities in Gammu or python-gammu should be reported privately. {% endblocktrans %}
